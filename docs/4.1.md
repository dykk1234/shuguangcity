# 曙光城 4.1 · 水上桥修复与渲染性能版

> 基于 4.0（`曙光城_CITYFORGE_4.0_智能交通版.html`）构建，4.0 及更早文件均未改动。

## 本版修复

- **水上桥不显示（核心 bug）**：河流与水面格上的道路建筑（即"桥"）此前完全没有绘制入口。4.0 主渲染循环里 `drawRoad` 只写在陆地分支，水面分支只画水、水花与岸线描边，于是数据层虽然是"水面格 + 道路建筑 = 桥"，画面上却只剩一片水。4.1 在水面分支补上桥面绘制分支，并新增独立桥体渲染模块：
  - 桥面板加厚并带下侧板，桥墩落水处带高光，远端护栏带立柱；
  - 桥面高度与岸上路面做四角平均混合，形成缓坡而不是台阶；
  - 车辆与施工预览（`carDY`）贴合桥面高度，不会穿模或悬空；
  - 只在"朝有道路相接的方向"画中心虚线，避免断头桥出现悬空虚线。
- **4.1 重构期间引入并已修掉的回归**：新版快速瓦片循环最初把对角线步进写成 `ax+=hw, ay+=hh`，正确值为 `ax+=2*hw`、`ay` 不变，导致每行瓦片越往右越偏移，出现大片"露出天空"的空洞。该问题在无头浏览器截图中定位并修复，现已整屏对齐。

## 本版性能

- **瓦片快速绘制**：改用标量递推投影（`ax/ay` 逐格加减，不再逐格调 `isoX/isoY`）、屏幕剔除、复用四边形数组（`qset/qdraw` 免分配）、平地草地色阶预计算（最常见瓦片不再逐格拼 `shade` 字符串）。
- **光晕精灵缓存**：太阳/月亮/灯光原本每帧新建数百个 `createRadialGradient`，改为按颜色缓存 96×96 精灵 + `drawImage`。
- **图表脏检查**：城市趋势图按数据签名（历史长度/首末值/尺寸/配色）跳过重绘。
- **道路中心虚线批处理**：`z<0.78` 时逐格 `stroke` 改为按扫描行合并成一次 `stroke`（1px 虚线肉眼无差别），高倍时仍保持逐格绘制。
- **远景交通设施裁剪**：`z<0.5` 不再绘制信号灯、站牌与公交站点图标。

### 实测（无头 Edge + SwiftShader 软件渲染，96×96 压测城，4491 建筑 / 3388 格道路，三轮中位数）

| 缩放 | 4.0 render | 4.1 render | 提升 |
|---|---|---|---|
| 0.45（全城） | 148.4 ms | 138.2 ms | 1.07× |
| 0.6 | 147.7 ms | 104.5 ms | 1.41× |
| 0.8 | 101.4 ms | 65.5 ms | 1.55× |
| 1.1 | 81.1 ms | 42.8 ms | 1.90× |
| 0.8 更新+绘制 | ≈130 ms | 66.0 ms | ≈1.9× |

低倍（0.45）基本持平：该档位每帧要铺满 7157 个瓦片，瓶颈在软件渲染的像素填充率，而不是绘制调用次数；同档位 CPU 侧的开销（字符串拼接、投影函数调用、分配）已被削减。真实 GPU 设备上这部分的收益会更明显，但**未做真机实测**，不作为性能承诺。

## 兼容与边界

- 存档前缀沿用 `cf4_save_`，并继续兼容读取 `cf3_` / `cf2_` / `cf_save_` 旧存档。
- 桥只由"水面格 + 道路"构成，与 4.0 数据完全一致：4.0 存档里的桥在 4.1 中会直接显示出来，不需要重建。
- 新增 `window.CFBRIDGE`（`isBridge/corners/deck/stats`）与 `window.CFPERF41`（`tiles/glowHits/glowMiss/chartSkips`）两个只读调试出口，便于后续排查，不影响玩法。
- 建筑未做 LOD（远景仍绘制完整建筑），256×256 及以上大地图仍建议开"性能优先"画质。
- 水面格上仍可能出现被路网切碎的小水塘，属地形生成的既有表现，本版未改变生成规则。

## 验证

- 构建：`node build-v41.cjs`（`CF_TEST=1` 时输出测试版到 `v41-test/`），构建后自带 `new Function` 语法检查；正式版 344139 字节，不含测试注入。
- 断言（`node bench-v41.cjs`，无头 Edge + CDP）：8 项全 PASS
  - 压测城路网 3388 格、找到可架桥水面并修路、桥面格识别 38 格、桥体绘制调用 12 次、桥面中心沥青色像素 8/9、桥两侧净水面成片为蓝、重算完成、存档往返一致。
- 反证：同一份 seam 注入 4.0 基线副本，桥面格识别为 **0 格**，确认"水上桥不显示"确实是 4.0 的缺陷，且 4.1 已修复。
- 正式版启动冒烟：无头 Edge 打开正式版 → 无 JS 异常、`CFBRIDGE`/`CFPERF41` 存在、可正常进入城市并渲染（`CFPERF41.tiles` 有值）。
- 尚未完成：真实用户设备上的满城长时间经营验收、多浏览器（Safari/Firefox）视觉验收。
