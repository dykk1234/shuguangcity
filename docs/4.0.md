# 曙光城 4.0 · 智能交通与城市分析版

## 本版新增

- **公交增强**：公交线路增加发车频率、抽象载客量、候车人数、容量和线路标签；可配置 `busFrequency`、`busCapacity`、路径缓存 TTL。
- **交通系统**：路径缓存带有效期，交通看板增加车辆、公交、候车、载客、拥堵、路径求解与缓存命中等数据；继续使用有限车辆预算，避免人口增长导致车辆无限增加。
- **图层可视性**：新增独立图层面板，可选择供水、供电、污染、消防、医疗、治安、交通流量等图层；支持透明度和当前图层显示/隐藏。切换图层会保留当前工具，不会误触施工。
- **城市看板**：增加人口峰值、住宅容量/入住率、岗位填充、基础设施供需、环境、空间占用、火情、空置住宅及地图规模统计。
- **性能**：交通路径采用 TTL 缓存；图层数据按地图修订和核心指标缓存；远景使用低细节渲染；新增自适应性能模式，在持续低帧率时切换性能优先画质。
- **快捷入口**：进入城市后可用 `L` 打开分析面板；原有城市指标面板继续保留。

## 兼容与边界

4.0 使用独立 `cf4_save_` 存档前缀，并兼容读取 3.0、2.0 和旧版存档。旧版道路等级按普通道路处理。公交载客为抽象模拟，不是逐乘客、完整班次调度；交通仍不模拟真实多车道、换道、立交和完整路口冲突。

性能缓存不会改变模拟结果，只减少重复计算。自适应画质可能在低性能设备上降低树木、烟雾等细节；放大后会恢复建筑细节。256×256 仍建议使用性能优先模式。
