规划要诀

② 工厂污染周边，公园与防护林可净化；滩涂地价更高。

📖 玩法说明

核心循环

  • 修路 → 所有建筑必须紧邻道路才能运作（跨水自动架桥）。
  • 建住宅 → 居民迁入需要：道路 + 电力 + 供水 + 就业岗位。
  • 商铺 / 工厂 / 农场 / 港口 → 提供岗位与税收，注意污染隔离。
  • 风车 + 水塔 + 垃圾回收站 → 电力全局电网，供水按半径，清运按全城容量。
  • 公园 / 消防 / 医疗 / 教育 / 治安 / 公交 → 幸福度决定人口增长。
  • 人口里程碑 → 解锁 38 种建筑中的高级设施，直至核电站与歌剧院。

市民与决策

  • 市民会提出诉求事件：公园请愿、噪音投诉、夜市许可、环保抗议……
  • 每个诉求有 2–3 个决策选项，花钱买民心，或拒绝承受后果。
  • 诉求超时无回应会损害幸福度；「市民」页可查看代表与街头舆论。
  • 市政政策（免费教育、医保、垃圾分类等）提供长期增益与月支出。

地形与沙盒

  • 地形含深水 / 浅水 / 滩涂 / 草地 / 林地 / 丘陵 / 山地，丘陵有高度差。
  • 「地形」工具栏可抬升 / 降低 / 造水 / 绿化，1–3 格笔刷拖动绘制（普通模式 ¥60/格，沙盒免费）。
  • 沙盒模式另有解锁全部、无灾害、天气控制、资金 / 人口注入、平整全城。
  • 天气随季节变化：雨天幸福略降，冬雪覆盖高地；沙盒可强制天气。

操作

  • 左键 放置 / 选择 · 道路 / 拆除 / 地形可按住拖动连续绘制；选择模式下按住左键拖动超过 8px 即平移地图。
  • 右键 / 中键拖动 平移 · 滚轮 缩放 · 触屏双指平移缩放。
  • P 暂停 · 空格拖动平移 · 1/2/3 速度 · B 拆除 · Esc 取消 · G 网格。
  • Ctrl/⌘+Z 撤销（最多 10 步）· Ctrl/⌘+S 存档 · WASD 平移 · M 静音。
  • 点击小地图快速跳转；「规划」页切换热力图层诊断城市。
