# 曙光城 4.1

单文件等距城市营造模拟游戏。一个 HTML 双击即玩，不用装环境、不用起服务、不联网。

> Single-file isometric city builder — double-click the HTML and play.

**下载：[`release/曙光城4.1.html`](release/曙光城4.1.html)**

## 怎么玩

打开后点「新游戏」，选地图尺寸和难度就能开始。从修路、拉电、供水起步，逐步引进住宅、商业、工业，靠税收和人口把城市往下滚。

- 左键建造，拖动可连续施工；右键拆除；`Esc` 取消
- 滚轮缩放，空格拖动平移，`P` 暂停
- `L` 打开城市分析面板：人口、财政、供需、污染、地价、交通
- 地图 24×24 到 256×256，昼夜与四季会跟着日期走
- 存档在浏览器本地，刷新不丢

## 版本 4.1 改了什么

- **修好了水面上的桥**：此前河流上的道路只画水不画桥面，看起来像"桥消失了"；现在桥有桥面、桥墩、护栏，车辆和施工预览也贴合桥高。
- **渲染更快**：重写了等距瓦片绘制（投影递推、屏幕剔除、不复用临时数组），光晕改为精灵缓存，低倍时虚线合并描边；中高倍率下渲染耗时约降到原来的 1/2～2/3。
- 存档前缀仍是 `cf4_save_`，兼容更早版本的存档；4.0 存档里的桥打开就能直接显示。

## 目录

- `release/` — 成品，直接玩
- `docs/` — 4.0、4.1 的详细变更记录
- `src/` — 游戏各层模块与 4.1 新增的桥体、性能模块
- `build/`、`tools/`、`benchmarks/` — 构建脚本、压测与截图工具、压测数据
